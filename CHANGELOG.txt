**v4.6.0 (SSA инфраструктура):**
- **MIR phi инструкции**: структуры `PhiInst`, `PhiIncoming` добавлены в `mir.zig`. BIR phi-узлы теперь понижаются до MIR phi-инструкций в `bir_cpu.zig` (вместо эмита inline-копий).
- **Проход уничтожения SSA** (`mir_ssa_destroy.zig`): полное устранение SSA как MIR-прохода — `computeNextVReg()` для выделения scratch-врегов выше всех существующих, `splitCriticalEdges()` вставляет транплинг-блоки на рёбра с >1 предшественником И >1 преемником, `eliminatePhis()` группирует копии по предшественникам, `resolveAndEmitCopies()` выполняет корректное параллельное разрешение копий (извлечение безопасных источников, разрыв циклов через scratch-регистры с полным эмитом `mov tmp, src` + `mov dst, tmp`).
- **Проход распространения копий** (`mir_copy_prop.zig`): пошаговое прямое распространение копий в пределах блока — разрешение цепочек врегов (`v2=v1; v3=v2` → `v3=v1`), устранение тождественных копий (`mov x, x`), инвалидация врегов-псевдонимов указателей при записях.
- **MIR Верификатор: `verifyNoPhis()`**: новая проверка, гарантирующая отсутствие phi-инструкций после уничтожения SSA; возвращает ошибку `PhiNotEliminated`.
- **Реорганизация пайплайна оптимизатора**: `Уничтожение SSA → verifyNoPhis → verifyMir → Распространение копий → DCE → Пеепхол ×3 → DCE`.
- **`mir_x64.zig`: `.phi => unreachable`**: phi, дошедший до кодогенерации, теперь паникует сразу вместо генерации неверного кода.
- **Исправление `emitCmpFlags`**: обработка двухоперандных случаев с immediate (например `cmp_flags #1, #0` от распространения копий) — загрузка первого immediate в scratch-регистр перед `CMP_R64_IMM32`.
- **Обёртка бэкенда** (`backend.zig`): единый модуль в `src/compiler/backend/`, реэкспортирующий подмодули BIR и MIR, решающий ограничение путей модулей Zig 0.14 для тестовых исполняемых файлов.
- **`regalloc.zig` обновлён**: вычисление интервалов жизни обрабатывает входные значения phi.
- **`mir_verify.zig`, `mir_dce.zig`, `mir_peephole.zig` обновлены**: все обрабатывают phi-инструкции (определяемые вреги, проверка побочных эффектов, пропуск phi в пеепхоле).
- **5 E2E тестов** (`test_bir_to_mir_e2e.zig`): `testSimpleRetConst` (42), `testSimpleAdd` (10+20=30), `testIfElse` (ветвление), `testIfElseWithPhi` (diamond CFG с phi → возврат 10), `testNeg` (-5). Все выполняют реальный x86_64 код через `VirtualAlloc` + `PAGE_EXECUTE_READWRITE`.
- Пайплайн: `Парсер → BIR (SSA) → mem2reg → cfgsimplify → BIR Verify → Понижение до MIR (SSA) → MIR Verify → Уничтожение SSA → verifyNoPhis → Распространение копий → DCE → Пеепхол → Линейный аллокатор → x64 → PE/COFF`.

**v4.5.4 (Полноценный expression parser + if/while/var + idiv):**
- **Recursive descent expression parser**: 6 уровней приоритета — `||`, `&&`, сравнения (`>= <= == != > <`), `+`/`-`, `*`/`/`. Поддерживает скобки, вложенные вызовы функций с аргументами, целые литералы, переменные.

**v4.5.3 (CLI + `.bp` → `.exe` end-to-end):**
- **CLI tool `bplus.zig`**: команды `bplus build <input.bp> [-o <output.exe>]` и `bplus run <input.bp>`. Парсер .bp строит MIR напрямую (fn, extern fn, return, вызовы, целые литералы, `+` выражения, параметры-переменные). Линковка через `zig build-exe` с `bplusrt.obj` и `-lkernel32`.

- **Прямой MIR builder**: MIR строится из распарсенных строк `.bp` без промежуточного BIR — vreg аллокация, param→vreg prologue, expression compiler.
